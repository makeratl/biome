Compact logs

            
Capture logs are append-only. Purge keeps gold + still-curatable turns and
               drops what can never be gold (losers' turns, fallbacks) plus your ✕ rejects — so the logs
               don't backfill forever. Originals are backed up to *.jsonl.bak.

Train a new generation — one-click distill → ollama create

            
Pick a data tier and a student base, name the generation, and run it. The server
               exports the tiered dataset, LoRA-tunes the student on those moves, and registers the result as a
               structured biome-<family>-<size>-<tier><version> model on the
               ladder. Training is GPU-exclusive — gameplay/tournaments pause while a run is active.
